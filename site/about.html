这是什么？

一个每天自动从国外新闻网站抓取要闻，用 AI 整理成中文简报的网站。

数据来源

  • 国际：BBC、Reuters、纽约时报
  • 科技：TechCrunch、The Verge

通过 RSS 订阅获取，无人工干预。

整理流程

  1. 每天定时抓取所有源最近 24 小时的新闻
  2. 用 DeepSeek AI 翻译成中文 + 提炼核心
  3. 按主题分类，生成简报
  4. 网站自动更新

更新频率

每天 UTC 0 点（北京时间早上 8 点）自动更新。

技术栈

  • 抓取：Python + feedparser
  • AI：DeepSeek Chat API
  • 展示：纯 HTML + CSS
  • 定时：GitHub Actions
  • 部署：GitHub Pages
