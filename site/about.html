这是什么？

一个每天自动从萨赫勒地区（西非与北非过渡地带）的新闻媒体抓取要闻，用 AI 整理成中文简报的网站。

覆盖地区

主要包括：

  • 核心萨赫勒：马里、布基纳法索、尼日尔（已退出西共体的三国联盟）
  • 萨赫勒边缘：乍得、毛里塔尼亚、塞内加尔、几内亚、冈比亚
  • 周边关注：科特迪瓦、贝宁、尼日利亚北部、苏丹

数据来源

国际媒体（综合视角）

  • France 24（法语 + 英语非洲频道）
  • Africanews（泛非英语新闻）
  • Al Jazeera（半岛电视台）
  • DW 德国之声非洲频道

区域聚合

  • AllAfrica 西非（90+ 非洲媒体聚合）
  • Sahel Express（萨赫勒专线）

本地媒体

  • Mali Actu（马里本地法语新闻）

关注议题

  • 安全：圣战武装袭击、军事政变、地区安全联盟（AES）
  • 政治：三国军政府动向、与法国/西方关系、退出西共体
  • 人道：流离失所、粮食危机、国际援助
  • 经济：制裁影响、跨境贸易、新兴合作（俄罗斯、中国）

整理流程

  1. 每天定时抓取所有源最近 24 小时的新闻
  2. 用 DeepSeek AI 翻译成中文 + 提炼核心
  3. 按议题分类，生成简报
  4. 网站自动更新

更新频率

每天 UTC 0 点（北京时间早上 8 点）自动更新。

技术栈

  • 抓取：Python + feedparser
  • AI：DeepSeek Chat API
  • 展示：纯 HTML + CSS
  • 定时：GitHub Actions
  • 部署：GitHub Pages
